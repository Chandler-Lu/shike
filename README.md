# 拾刻计划

**把零散安排，收进日历。把重要日子，放在心上。**

拾刻计划是一款手绘手帐风的日程与倒数日 App。贴一段文字、选一张截图，整理下一次见面；写下想做的事，把想法慢慢变成计划。期待中的旅行、已经走过的纪念日，都有自己的位置。

## 随手记下，在每一块屏幕上展开

在 **iPhone** 随手记，在 **iPhone Duo、iPad、Mac** 展开安排，把重要日子带到 **Apple Watch** 的腕间。同样的纸张底色、手写字和兔兔猫咪，在不同屏幕上展开不同的空间。

![拾刻计划：iPhone、iPhone Duo、iPad、Mac 与 Apple Watch](promotion/01-platforms.png)

| 设备 | 适合你的使用方式 |
| --- | --- |
| **iPhone** | 粘贴、拍照、语音输入，随手查看当天安排。 |
| **iPhone Duo** | 收起时轻松记录；展开到宽屏后，并排核对原文与结果、问答与计划，或一边翻看日子一边查看详情。 |
| **iPad** | 横竖屏自适应，宽屏下并排整理，侧边栏切换日历、倒数日和记录。 |
| **Mac** | 在大窗口整理计划，拖入图片与文本，用键盘快捷键快速操作。 |
| **Apple Watch** | 抬腕查看正数日、倒数日和详情，按分组筛选，也能放进智能叠放。 |

展开或收起 Duo、旋转 iPad、调整 Mac 窗口，继续刚才的输入与编辑；布局随可用空间变化，大字号下保留易读的单列。Mac 支持 ⌘1–5 切换页面、⌘N 新建、⌘O 导入文件、⌘⇧V 导入剪贴板、⌘F 搜索、⌘, 打开设置。

开启 iCloud 后，倒数日、分组、接口配置与使用偏好可在设备之间同步。Apple Watch 从配对的 iPhone 接收日子，离线时也能查看已同步的内容。

## 先了解，再好好安排

“去北京玩一天，上午逛故宫，下午留点时间散步。”

照常点击 **帮我安排**。拾刻计划会通过问答补充偏好，再把想法整理成可以修改的日程。开启联网搜索后，需要外部信息时会查找开放时间、预约要求和活动资料，并附上参考来源，让计划更有依据。

![联网搜索规划：参考开放时间与预约说明，整理可修改的日程](promotion/02-online-planning.png)

- **已有安排，直接提取**：文字、截图、照片和语音都能成为输入，整理名称、开始与结束时间、地点和备注。图片文字由系统在设备上识别。
- **还没想好，一起规划**：补充偏好，避开已有的定时日程；全天日程不占用可安排时段。继续追问，或重新开始一轮安排。
- **核对后加入日历**：每一条都可以编辑；模糊信息逐项确认。手动指定日历，或按日程类别优选合适的日历。
- **看清接下来的几天**：当天、3 天、7 天视图，左右滑动切换日期，长按空白处新增，拖动日程调整时间。
- **回顾与追问**：把当前日历整理成结构化总结，继续提问，复制为纯文本或 Markdown。
- **截图变日程**：通过系统捷径“截屏 → 拾刻计划”，识别当前页面，再核对提取的安排。

在「设置 → 模型与 API」开启联网搜索，选择**博查或 Tavily**，填入搜索 API Key 即可启用。普通任务直接规划，需要资料时再查询。搜索结果供核对，交通耗时等缺少专用数据支持的信息会标明估算。

## 把重要的日子，画成一张纪念卡

生日、旅行、相识的第一天，都值得被记住。倒数日支持公历与农历、分组与置顶、重复日期、秒级计时，也可以用自然语言一次添加多个日子。

![倒数日：柔和纸色、竖版分享卡片与兔兔猫咪手绘插画](promotion/03-countdowns.png)

为每个日子选一张喜欢的“纸”：**原纸色、奶油黄、蜜桃粉、鼠尾草绿、雾蓝、浅丁香**。计数字色随底色柔和搭配，深色模式也保持清楚。颜色用于 App 内的列表与详情，让纪念有一点自己的模样。

单列卡片、双列卡片、窄条列表随心切换；下拉搜索，再拉深一点就能新增。长按多选，一起移动分组或删除。顶部年度彩条轻点一下，在“今年已过”与“今年剩余”之间切换。

为满周年、每 100／500／1000 天，或特别的 520、1314 天设下提醒，也可以自定义间隔、选择包含起始日。

点详情中的计数，切换天、周、月、年，退出后恢复按天显示。分享卡片沿用当前计数方式，搭配 **21 张兔兔和猫咪彩铅手绘插画**，把重要时刻做成一张竖版纪念卡。

## 在意的日子，一眼就看见

还有多久出发，已经相伴多少天。**正数日与倒数日都能放进小组件**，让期待与纪念出现在每天都会看到的地方。

![桌面、锁屏与 Apple Watch 智能叠放小组件](promotion/04-widgets.png)

| 展示位置 | 小组件体验 |
| --- | --- |
| **iPhone、iPad 主屏幕与 Mac 桌面** | 小、中、大三种尺寸，配上日期与年度进度，显示本年度剩余天数。 |
| **iPhone 锁屏** | 行内、圆形、矩形三种样式，抬起手机查看计数，点击直达对应日子。 |
| **Apple Watch 智能叠放** | 在腕间查看日子，点击进入手表 App 了解详情。 |

每个小组件都可以有自己的关注点：**显示全部、只看一个分组，或固定一到两个日子**。

## 记下的日子，好好留住

iCloud 同步，让倒数日与使用偏好跟着你走。自动备份，给记录多留一份安心。

![本地与 iCloud Drive 自动备份：各保留最近 20 份，预览后合并恢复](promotion/05-backup.png)

- **本地与云端，各留一份**：可同时备份到本地与 iCloud Drive，每台设备各保留最近 **20 份**副本；数据变化、打开或离开 App 时检查备份。
- **先看，再恢复**：导入拾刻计划 JSON 备份前，先预览内容，并自动备份当前数据。
- **合并新内容**：保留本机已有记录，历史日程不会自动重复加入系统日历。

备份包含倒数日、分组、原文、日程草稿、记录、问答和设置；API Key 与原图不写入备份。

## 用你习惯的 AI，按你的方式安排

支持保存多个 **OpenAI 兼容接口**，自定义服务地址、获取模型列表或手动填写模型，填写后自动保存。提取日程与帮我安排各有一套可编辑的提示词。

提取、安排与总结时，可以先去做别的事。系统允许时，切到后台或锁屏仍会继续处理；结果保存后发送完成通知，也可在「设置 → 模型任务与结果」查看。

首次向模型服务发送提取或安排内容前，会说明范围并征求同意；日历总结由你点击发起，使用当前显示日程的标题、时间与地点。API Key 由系统钥匙串保管。拾刻计划不设开发者数据服务器，也不接入广告追踪。

## 从这里开始

1. 在设置中添加你使用的模型接口。
2. 粘贴一段安排，选择「提取日程」；或者写下目标，选择「帮我安排」。
3. 核对、修改，加入你选定的日历。

手动管理倒数日、查看小组件与手表不需要调用 AI。AI 与联网搜索功能需自备可用接口，费用由所选服务商决定。

适用于 **iOS / iPadOS 17 及以上、macOS 14 及以上**；Apple Watch 需 **watchOS 10 及以上**，并配对安装拾刻计划的 iPhone。
