拾刻计划隐私政策
生效日期：2026 年 10 月 17 日 · 版本 7
开发者：Chandler-Lu
联系邮箱：shike@yeslu.cn

1. 拾刻计划如何处理内容
拾刻计划将你主动输入、粘贴、选择或分享的文字和图片整理为日程。应用不会在启动时自动读取剪贴板。iPad 和 Mac 使用相同的内容处理规则；Mac 仅在你选择文件或主动拖入时读取对应图片和纯文本，不扫描其他文件。图片通过 Apple Vision 在设备上识别，不会将原图上传给模型服务。首页相册按钮使用系统照片选择器。桌面长按图标的“从最近一张图片导入”需要另行申请照片读取权限，只取授权范围内按创建时间最新的一张图片；有限授权时不代表整个相册的最新图片。iCloud 图片可能由系统下载到设备后再识别，拍照时才申请相机权限。只有主动选择剪贴板快捷操作或粘贴按钮时才读取剪贴板。

通过分享菜单导入的文字和图片先暂存在本机，打开主 App 后继续识别与提取。通过系统快捷指令传入的截图在设备上完成 OCR，仅识别后的文字进入本地待处理队列和导入记录；截图不交给模型。捷径不会持续读取屏幕。语音录入仅在你主动开始时申请麦克风与语音识别权限，优先使用设备端识别，不支持时可能使用 Apple 在线语音服务；应用不保存录音。确认转写文字后再按正常流程提取日程。

2. 你选择的第三方模型服务
提取日程需要你配置自己的 HTTPS 接口地址、模型及 API Key。首次向某个服务发送内容前，拾刻计划会显示接收地址和发送范围，获得你的明确允许后才发送原文（包括 OCR 识别结果）、参考日期、时区、指定的日程类别和你设置的提示词。开启按类别自动选择日历时，还会发送可写日历名称和仅用于本次请求的候选编号，不发送真实日历标识、账户名称或已有事件的标题、地点和备注。
使用“帮我安排”时，还会经独立范围授权发送本次目标、问答记录和待修改的方案。允许日历访问后，应用在本机计算参考日历的可用时间区间，并经授权发送这些区间以避开已有安排；不发送用于计算的已有事件标题、地点、备注或真实标识。每轮发送前重新检查实际接收地址与范围。
使用倒数日“自然语言识别”时，经上述文字发送授权，将本次主动输入的描述、参考日期和系统时区交给所选模型服务。已有倒数日记录和分类列表不会发送；识别结果在本机核对和修改，主动保存后才加入倒数日。
在日历页点击“总结”，即直接将当前日期范围和显示日历内的日程标题、起止时间、全天标记及地点发送到当前选中的模型接口，不再二次确认。不发送事件备注、真实日历/事件标识、账户名称或倒数日记录。总结可复制为纯文本或 Markdown，不修改日历，也不自动保存到导入记录；为支持后台完成后查看，会保存在本机模型任务记录中。

API Key 通过请求头发送给该接口，用于认证；不写入 URL。测试连接只发送应用内置的示例日程；获取模型列表发送认证信息但不发送你的原文或日历名称。网络服务通常也能接收连接所需的 IP 地址等信息。第三方是否保留请求、保留多久、是否用于其他用途，应以你所选择服务提供方的政策和账户设置为准。拾刻计划无法替你删除第三方已经收到的内容。请仅使用你了解并信任、且有权使用的服务；服务商可能另行收取 API 费用。
改变接收地址，或扩大到发送日历名称、安排问答、可用时段时需要重新允许。旧的提取授权不自动覆盖新增安排范围。在设置中的“关于内容与隐私”可撤销本设备的模型发送授权，之后提取时会重新询问。撤销不影响已发送的请求。授权在主 App 和分享扩展间共用，不通过拾刻计划的设置同步传至其他设备。

开启“模型与 API”中的“联网搜索”并填写配置，表示允许本设备向你选择的博查或 Tavily 官方搜索接口发送模型生成的必要查询词（可能包含目标中的地点、活动和日期），并访问搜索结果中的公开网页。搜索请求不包含已有日历事件、完整问答或模型 API Key；搜索密钥仅发送至所选服务的官方搜索接口，不支持自定义搜索地址。取得的有限文字摘录、来源链接和查询时间会交给当前模型用于安排，并随本次问答保存在设备及你启用的 JSON 备份中，不保存完整网页 HTML。网页读取不使用登录状态、不执行脚本。配置按现有 iCloud 开关同步，搜索 Key 单独存放在钥匙串；发送授权仅保存在本机，不随同步或备份转移。新设备需在设置中开启本机授权。关闭搜索会停止后续搜索工具调用，已有资料保留；可删除对应记录和备份。搜索及来源网站会接收连接所需的 IP 地址等信息，数据处理与费用以各服务政策为准。搜索失败或来源不足会标明未核实，加入日历前请核对。

3. 日历权限
应用在你使用日历功能时申请完全访问权限，以显示当天、3 天或 7 天的事件、筛选日历、计算空闲时段、添加你确认的事件，并通过系统编辑器修改或删除可写日历中的事件。只读日历只能查看。长按空白处可新增，长按可写日程拖动会直接修改它的时间；重复日程只修改选中的这一次。帮我安排只发送获准的可用时间区间；日历总结按上一节所述发送标题、时间与地点。解析结果先保存为可编辑草稿；只有你确认加入时才写入系统日历。系统日历事件是否同步及如何保存，由你的日历账户和系统设置决定。

4. 本地保存与删除
原文、问答、安排方案、草稿和导入记录保存在设备的应用共享容器内。模型任务的结果、倒数日识别输入和任务状态另保存在本机，可在“设置 → 模型任务与结果”中删除；不包含 API Key。结果使用系统文件保护，设备首次解锁后可在锁屏期间继续保存。运行中的密钥只在内存中使用，钥匙串保护方式不变。仅在后台完成时发送系统通知，通知仅含任务类型和数量，不含日程原文、标题或地点；拒绝通知权限不影响识别和保存。后台执行受系统资源与执行时限约束，强制退出不保证继续。暂存图片采用系统文件保护并排除备份，OCR 成功后删除。未完成 OCR 的图片会保留以便恢复，可在导入页移除。你可以在“记录”删除导入记录；这不会删除已经写入系统日历的事件，事件可在拾刻计划日历页的系统编辑器或系统日历中另行删除。系统设备备份可能包含本地记录，受 Apple 的备份设置和政策管理。
API Key 保存在系统钥匙串，不进入普通偏好或应用日志。删除接口会移除该配置；为避免离线设备错配凭据，旧版 Key 条目可能继续保留在钥匙串中。需要彻底停止一个 Key 的使用时，请在服务提供方撤销该 Key。卸载应用不保证删除钥匙串、系统备份、已同步设置或日历中的数据。

5. 可选 iCloud 同步
设置、API 与倒数日共用一个同步开关，默认关闭。你开启后，接口名称、格式、地址、模型、当前选择以及日历名称、账户、显示天数、显示和规划参考日历、时区偏好，以及提取和安排的自定义提示词通过 Apple iCloud 键值存储同步；API Key 通过 iCloud 钥匙串同步；倒数日名称、日期、重复规则、备注、分类、置顶和提醒设置通过 CloudKit 私有数据库同步。需使用同一 Apple 账户并开启相应系统能力。此功能不主动同步日程原文、图片、问答、方案和导入历史，当前浏览位置仅保存在本机。倒数日删除标记保留在私有数据库中，以防离线设备恢复已删除记录；切换 Apple 账户时暂停倒数日同步并保留本地记录，不自动传给新账户。
关闭开关仅停止当前设备后续设置和倒数日同步，保留本机数据，不会清除其他设备或云端副本。需要停用云端数据时，请在相关设备关闭同步并通过 Apple 账户及 iCloud 数据管理功能处理；需要使凭据失效，请在服务商处撤销。Apple 服务的数据处理受其隐私政策和你的账户设置约束。

倒数日与导出
倒数日可不使用系统日历权限，显示在拾刻计划自己的日历全天区域，不自动写入系统日历或发送给模型。提醒默认关闭，主动设置后才请求本设备的系统通知权限；各设备独立安排最多 60 条后续本地通知，在内容变化及打开应用时滚动更新。通知标题可能出现在系统锁屏上，可在系统设置中关闭预览。设置中的 JSON 导出包含倒数日、原文、备注、问答、草稿、保存状态、普通设置、接口地址和提示词，不包含 API Key、凭据标识、发送授权、原图或系统事件内部标识。导出文件保存到你在系统文件选择器中指定的位置；如选 iCloud Drive，则由系统同步文件。文件不自动脱敏原文，请自行管理、分享和删除。支持导入拾刻计划自己的 JSON 备份；先校验并预览，按编号合并，保留本机已有记录。恢复的日程不会自动再次写入系统日历，新增接口的 API Key 需另行填写。暂不支持 Days Matter 的加密备份。单个倒数日可在设备上生成卡片图片，只有你主动分享或保存时才交给所选目标；选择保存到照片时，系统会请求照片添加权限。图片包含卡片名称、目标日期和当前计数，请自行管理分享范围。

桌面小组件与 Apple Watch
iPhone 锁屏小组件及 iPhone、iPad 和 Mac 的桌面小组件通过各自设备的本机共享空间读取倒数日展示数据。配对 Apple Watch 使用 Apple WatchConnectivity 接收名称、日期、分类、重复和计数规则，在手表本地保存供 App 与智能叠放显示；不传送原文、问答、备注、API Key 或模型接口配置。手表断连时可显示已同步内容。锁屏、桌面和手表上的名称可能被旁人看到，可自行移除组件。

自动备份
自动备份和备份到 iCloud Drive 默认开启，可在设置“数据与备份 → 自动备份”分别关闭。数据变化后、打开或离开 App 时检查，内容变化才产生自动副本；应用关闭时不保证定时备份。备份内容与 JSON 导出相同，包含原文、备注、问答和普通设置，不包含钥匙串密钥、授权记录或原图。每台设备在本地与 iCloud Drive 的独立目录各保留最近 20 份，导入前也会保存一份。云端通过 Apple iCloud Drive 处理，关闭备份不删除已有副本；备份中的旧内容可能仍包含之后删除的记录。可从本地备份列表导出或恢复，并在系统“文件”App 的“iCloud Drive → 拾刻计划 → Backups”管理云端文件。账号变化时暂停后续云端备份，需确认账号后重新开启。

6. 开发者与跟踪
拾刻计划没有开发者运营的内容服务器、广告 SDK、分析 SDK、跨应用跟踪或应用账号系统。开发者不通过上述功能接收你的日程内容或 API Key。你主动邮件联系时，开发者会使用你提供的信息处理支持请求；请勿在邮件中发送 API Key 或不必要的敏感内容。

7. 你的选择与政策更新
你可在系统设置中调整相机、麦克风、语音识别、日历和 iCloud 权限，也可以选择不发送给第三方模型，保留本地文字与草稿。第三方模型可能出错，请在加入日历前核对日期、时间、地点和目标日历。
如处理方式发生变化，我们会更新政策日期；提取和安排扩大模型发送范围时重新征求允许，日历总结由每次点击主动发起。隐私问题或数据处理请求请联系 shike@yeslu.cn。在线版本：https://github.com/Chandler-Lu/shike/blob/main/PRIVACY.md 。
